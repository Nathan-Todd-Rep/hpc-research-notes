# Linux Refresher

## Overview

Linux is an open source operating system commonly used in web servers and embedded applications.

## Boot Process

1. When you turn on a Linux machine, a **bootloader** first loads the system into memory.
2. The **kernel** is the seed from which the rest of the OS grows.
3. The kernel is divided into subsystems like a process scheduler and device drivers.
4. A shell is provided by the GNU project.

## Useful Commands

| Command | What It Does |
|---|---|
| `grep` | Search for text inside files |
| `du` | Show disk usage for a file or directory |
